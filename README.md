# FreePencil2

3Dモデルから線画を自動生成する Blender アドオンです。

モデルを頂点カラーで自動的に塗り分け、その色境界をコンポジタでエッジ検出して
線として抽出します（いわゆる塗り分け法）。原理が単純なぶん高速で、
128万ポリゴンのモデルでも30秒弱で処理できます。

塗り分け法の難しさは「どう塗り分けるか」という前処理にありました。
FreePencil2 はそこを自動化しています。

- 二面角の分布から分割角度を自動判定
- 隣接グラフを彩色し、隣り合う領域が十分な輝度差を持つことを保証
- 微小領域の自動マージ
- 接するパーツ同士のトーン分け
- リグ検出によるボーン単位の塗り分け

STEP0 の「全自動セットアップ」を1回押すだけで、塗り分けからコンポジタの
ノード構築まで完了します。

## 対応バージョン

**Blender 4.5 / 5.2**（同じパッケージで両対応）

## ビルドとインストール

配布用の zip は Blender の CLI で作れます。

```bash
blender --command extension build --source-dir . --output-dir dist
```

生成された `dist/freepencil2-*.zip` を、Blender の
**編集 → プリファレンス → アドオン → ▼ → ディスクからインストール**
で導入してください。

## リポジトリ構成

- アドオン本体はリポジトリ直下
- `external_resources/` — ノードグループの生成スクリプト（4.x 用と 5.x 用）
- `locale/` — 翻訳ファイル
- `dev/` — 開発用の評価パイプラインと回帰テスト（アドオンの動作には不要）
