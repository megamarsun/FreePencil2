## Release 本文

## 何が変わったか

v3.0 は目玉の機能を足さず、BlenderKit・MMD・AI が作った 3D など 100 体あまりのモデルに素の STEP0 を当てて、出てきた絵の崩れを直した版です。直すたびに同じモデルを撮り直し、前後を画像で比べました。調整に使っていないモデルで 3 巡確かめています。

### セルの光と影の形（STEP3 のセル）

- **光の向き**: 既定を［カメラから］に。画面の左右・影の量・高さで日を向け、日がカメラに付いて行きます
- **影の形**: 腕と脚は筒、頭と髪は球、丸い部品は楕円体として影を取ります。シワや三角形のまだらの影が消えます
- **影の形を追ってアニメをレンダー**: 1 コマずつ、骨で動く物の影の形をそのコマのポーズで作り直して撮ります
- **アニメの影色**（既定）、**顔の影**（既定はいつも日なた）、**2 影**（すき間）、**リム**（縁の光）、**落ちる影を簡単な形に**
- **キャラと背景で光を分ける**（既定は切）: セルはキャラだけに掛け、背景は場面の光の通常の陰影のまま出します。キャラの落ち影も場面の光から落ちます

### キャラ

- **VRM**: MToon の出力を止めて描き、顔と目を 1 色に、口の中を塗り分け、指の節ごとの線を消します。「FreePencil を外す」で戻ります
- **骨の無い人物**（AI が作った人）を見分けて絵の線を当てます（強さ 0.35）。親子で組んだ物の部品は外します
- **骨付きのメカ**は、仕上がりがキャラでも精密で塗ります
- 半透明の重ね物（髪の影・頬の赤み）、切れ目の線、トゥーンの殻、毛の眉毛、顔のリグのしみを STEP0 が直します
- キャラの線の強さ 0.6 → 0.25

### 線

- **AI が作った 3D**（.glb）のひび割れのような線、メカに散る黒い点、でこぼこの面の汚れのような点を直しました
- **木の葉をかたまりで描く**、**内側（丸み）の線**（既定は切）
- 木の枝・ヤシの葉が黒く潰れる、卵のしま模様、窓ガラス・角膜のざらざら、LOD の重なり、頂点に色を持つスキャンのまだらを直しました
- 大きなモデルの STEP0 を短縮しました（89 万面 116 秒 → 42 秒の例）。絵は変わりません

### セルの色

- 色を見た目の明るさの上で白へ寄せ、くすまないように。黒い材質が黒く沈まないように。金属・ガラスを地の色で
- 細かい凹凸の影のざらざら、5.2 のリムの黒い帯、アニメのレンダーで［カメラから］の日が前のコマのカメラで回っていたのを直しました
- 影を落とす光が多い場面で、4K の床の影が欠けてちらつくのを直しました（影のプール 1024MB・影の解像度 0.75）

## 対応バージョン

同じ ZIP で 4.2 LTS / 4.3 / 4.5 LTS / 5.2 LTS。自動テスト 126 本を 4 版すべてで通し、見え方の監査（基準の絵と並べて比べる）も確かめています。
